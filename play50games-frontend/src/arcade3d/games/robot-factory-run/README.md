# Robot Factory Run

Menu 2 game 13, World 1 Ember Heights. Signature: route live moving power cells by rolling over wired switch plates. Five factory configurations culminate in Overseer M-8: cells into the chest, reversing its belt into presses, then catwalk roll-drops into the vents.

Uses the shared Menu 2 heroes/animation, orbit, stars, flow, secrets, boss, progress, local multiplayer and core intro/audio/rendering. Riko is the world default. Every hero can clear every level via the main route.

See `.handoff/K-m2-robot/HANDOFF.md` at repository root for level details, controls, hero routes, multiplayer, score proofs, pinned server limits and outstanding Claude playtests. `proof.test.ts` exercises every level through the real store at 30, 60 and 144 Hz.
